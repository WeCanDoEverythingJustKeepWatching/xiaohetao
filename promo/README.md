# 小核桃数字教材 · 高教B端官方宣传单页

简约商务、专业稳重的高校教育数字化转型宣传单页。单文件 HTML（`index.html`）内含全部样式与交互脚本，配套媒体资源目录 `covers/`、`videos/`，可整体拷贝部署到任意静态服务器。

## 页面结构（固定顺序）

1. **首屏 Banner** — 主标题「小核桃数字教材」+ 副标题「交互式数字教材，助力高校教育数字化转型」
2. **政策导向** — 政策卡片 + 标签筛选（国家级 / 江西省省级 / 行业指导意见），点击弹窗放大截图 + 右侧解读 + 「查看 / 下载政策原文」
3. **数字教材优势与创新亮点** — Tab 切换（核心优势 / 创新亮点）+ 截图横向滑动 + 轻量动态图标
4. **案例视频 + 数字资源库**（合并）— 7 个案例（MG 动画 / 数字人微课 / VR 虚拟仿真 3 个国家一流课程），支持分类筛选、关键词搜索、视频弹窗播放；底部含**虚仿资源平台跳转按钮**
5. **行业解决方案** — 三套定制方案 Tab（智慧课堂 / 院系资源定制 / 混合式课程配套）+ 部署架构简图 + 流程节点悬浮说明 + **官方平台网站跳转按钮**
6. **联系我们 & 合作咨询** — 商务微信二维码（占位，待替换）+ 咨询电话；导航、首屏及体验区按钮点击直达该板块，转化渠道归集到扫码与电话

## 部署方式

1. 将整个目录（`index.html` + `covers/` + `videos/` + `README.md`）上传至任意静态站点服务（Nginx、OSS 静态托管、GitHub Pages 等）。
2. 保持目录内相对路径不变即可，无需编译构建。
3. 本地预览：在目录内起一个静态服务后访问，例如 `python -m http.server 8899` 后打开 `http://127.0.0.1:8899/index.html`。
   > 注意：直接用 `file://` 双击打开时，浏览器可能阻止视频等本地媒体加载，建议通过 HTTP 服务预览。
